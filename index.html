[01] ¿QUÉ ES ARDUINO?

Arduino es una plataforma electrónica de código abierto que se utiliza para crear proyectos tecnológicos. Está formada por una placa programable (microcontrolador) y un software donde se escribe el código para darle instrucciones. (Arduino, 2023)

CEREBRO DEL PROTOTIPO ACTIVADO

[02] OBJETIVOS GENERALES Y ESPECÍFICOS

Objetivo general: Construir una estación meteorológica con Arduino para medir variables ambientales como temperatura, humedad, presión o intensidad de luz y registrar datos útiles para el análisis del clima local.

Objetivos específicos: Investigar componentes, seleccionar instrumental preciso, construir el circuito electrónico, programar el microcontrolador y procesar logs ambientales.

[03] METODOLOGÍA EXPERIMENTAL

Investigación de tipo experimental y descriptiva orientada al ensamblaje de un prototipo funcional bajo las siguientes fases:

  1. Investigación base de estaciones meteorológicas.
  2. Selección analógica de sensores.
  3. Diseño del esquema de conexiones.
  4. Codificación e instrucciones de software.
  5. Pruebas de estrés y calibración en campo.

[04] COMPONENTES Y MATERIALES

  • Placa Arduino Uno
  • Sensor DHT11 / DHT22
  • Barómetro BMP180
  • Sensor de luz LDR
  • Pantalla OLED 0.91"
  • Protoboard y Jumpers
  • Computadora / Cable USB
  • Fuente de alimentación

[05] ARQUITECTURA VISUAL DE CONEXIONES

Esquema técnico para la distribución de voltajes y pines analógicos/digitales en el Arduino UNO:

Módulo Electrónico Pin del Sensor Pin de Entrada Arduino
Pantalla OLED 0.91" VCC / GND 5V / GND
SCL A5 (Reloj Analógico)
SDA A4 (Datos Analógicos)
DHT22 / BMP180 VCC / GND 5V / GND
DATA / SDA Pin Digital / A4
Sensor Fotoresistencia LDR VCC / GND 5V / GND
A0 A0 (Señal Analógica)
