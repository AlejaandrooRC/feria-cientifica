✦ 01 // ¿QUÉ ES ARDUINO?

Arduino es una plataforma electrónica de código abierto que se utiliza para crear proyectos tecnológicos. Está formada por una placa programable (microcontrolador) y un software donde se escribe el código para darle instrucciones. (Arduino, 2023)

"El cerebro central que orquesta el monitoreo climático en los recintos."

✦ 02 // OBJETIVOS DEL PROYECTO

Objetivo general: Construir una estación meteorológica con Arduino para medir variables ambientales como temperatura, humedad, presión o intensidad de luz y registrar datos útiles para el análisis del clima local.

Objetivos específicos: Investigar componentes de campo, seleccionar sensores de alta precisión, ensamblar la placa, programar instrucciones de control y registrar el historial climático local.

✦ 03 // METODOLOGÍA Y FASES

Investigación experimental y descriptiva estructurada para evaluar el rendimiento de la central meteorológica en tiempo real:

  1. Investigación documental del microcontrolador.
  2. Selección de componentes de lectura analógica.
  3. Esquematización del circuito en protoboard.
  4. Desarrollo de instrucciones de código.
  5. Fase de pruebas y calibración perimetral.

✦ 04 // MATERIALES DE CAMPO

Hardware integrado para la recolección y lectura de variables meteorológicas:

  • Placa Arduino Uno
  • Sensor DHT11 / DHT22
  • Barómetro BMP180
  • Sensor de luz LDR
  • Pantalla OLED 0.91"
  • Protoboard y Jumpers
  • Computadora / Cable USB
  • Fuente de alimentación

✦ 06 // RESULTADOS Y DISCUSIÓN

Resultados: El desarrollo fue un proceso retador, logrando un sistema funcional que ayuda a determinar el clima de forma accesible y económica.

Planteamiento del problema: Las escuelas carecen de herramientas en tiempo real debido al alto costo de equipos profesionales. Arduino rompe esta barrera, facilitando el aprendizaje de tecnología y ciencias.

✦ 07 // CONCLUSIÓN ANÁLISIS EN CAMPO

A través del procesamiento continuo de datos ambientales, se concluye que el clima de Panamá es sumamente variado, húmedo y cambiante, consolidando la necesidad de implementar sistemas automatizados de bajo costo para su estudio práctico.
